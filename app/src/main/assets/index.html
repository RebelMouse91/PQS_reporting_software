Пока нет спрятанных фото.
Нажмите «Спрятать из галереи», чтобы убрать сюда уже снятые фото — они исчезнут из галереи. Или «Снять фото»: новый снимок сразу останется только здесь.
Как пользоваться

Спрятать фото из галереи

Кнопка «Спрятать из галереи» открывает системный выбор фото. Выбранные снимки копируются в собственное хранилище приложения и удаляются из галереи — их не увидят ни галерея, ни другие приложения.

Снять фото

Кнопка «Снять фото» открывает камеру телефона. Готовый снимок сохраняется сразу в тайник приложения в полном качестве и вообще не попадает в публичную галерею.

Просмотр

Нажмите на превью, чтобы открыть фото на весь экран. Стрелками по бокам — переход к соседним снимкам.

Выбор нескольких

Долгое нажатие на превью включает режим выбора — можно отметить несколько фото и сразу удалить их или вернуть в галерею.

Вернуть в галерею

Кнопка «В галерею» (в просмотре или при выборе нескольких) копирует фото обратно в публичную галерею и убирает его из тайника.

Удаление

Кнопка «Удалить» стирает фото из тайника без возможности восстановить — храните важное отдельно.

Данные

Все фото хранятся только на этом устройстве, интернет не нужен. Удаление приложения удалит и спрятанные фото вместе с ним.
