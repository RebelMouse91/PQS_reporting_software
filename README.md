# PQS — Android

Приложение целиком лежит в одном файле `app/src/main/assets/index.html`.
Android-часть — это только оболочка вокруг него: окно WebView, кнопка «назад»
и сохранение CSV в папку «Загрузки». Интернет приложению не нужен.

---

## Как получить APK, ничего не устанавливая

Сборкой займётся GitHub — там Android SDK уже стоит.

1. Зайдите на **github.com**, зарегистрируйтесь, если аккаунта нет.
2. Нажмите **New repository**. Имя — любое, например `kniga-ucheta`.
   Тип оставьте **Private**, если не хотите показывать код. Кнопка **Create repository**.
3. На странице пустого репозитория нажмите **uploading an existing file**.
4. Перетащите туда **всё содержимое этой папки** — вместе с папками `app` и `.github`.
   Проще всего: распаковать архив, выделить всё внутри и перетащить в окно браузера.
   Важно: заливать нужно сами файлы, а не папку `uchet-android` целиком.
5. Внизу нажмите **Commit changes**. Сборка запустится сама.
6. Откройте вкладку **Actions** сверху. Там появится запуск «Сборка APK».
   Подождите 3–5 минут, пока не появится зелёная галочка.
7. Откройте этот запуск, внизу страницы блок **Artifacts** →
   скачайте **pqs-apk**. Внутри архива лежит `app-debug.apk`.

Если галочка красная — откройте запуск, нажмите на шаг «Собрать APK»,
и пришлите мне последние строки лога.

## Как поставить APK на телефон

1. Перекиньте `app-debug.apk` на телефон любым способом.
2. Откройте его через файловый менеджер.
3. Android спросит разрешение ставить приложения из этого источника — разрешите.
4. Приложение появится в списке программ под именем «Книга учёта».

## Постоянный ключ подписи (важно для сохранности данных)

Без своего ключа сборка подписывается отладочным ключом, который на каждом прогоне
GitHub Actions генерируется заново. Android считает такие APK разными приложениями:
поставить новую версию поверх старой нельзя, только удалив приложение — а вместе с
ним удаляются баланс, локации, тарифы и история.

Чтобы этого больше не происходило, ключ создаётся один раз и кладётся в секреты
репозитория. На компьютере с установленной Java:

```
keytool -genkey -v -keystore pqs.keystore -alias pqs -keyalg RSA -keysize 2048 -validity 10000
```

Придумайте пароль и запомните его — восстановить ключ нельзя. Затем переведите файл
в текст:

```
base64 -w0 pqs.keystore > pqs.keystore.txt
```

В репозитории **Settings → Secrets and variables → Actions → New repository secret**
добавьте четыре секрета:

| Имя | Значение |
|---|---|
| `PQS_KEYSTORE_BASE64` | содержимое `pqs.keystore.txt` |
| `PQS_KEYSTORE_PASSWORD` | пароль хранилища |
| `PQS_KEY_ALIAS` | `pqs` |
| `PQS_KEY_PASSWORD` | пароль ключа |

Сам файл `pqs.keystore` храните отдельно и в репозиторий не кладите. Пока секретов
нет, сборка продолжает работать на отладочном ключе.

## Как обновить приложение потом

Поменялся только `index.html`:

1. В репозитории откройте `app/src/main/assets/index.html`.
2. Карандаш справа сверху → вставьте новое содержимое → **Commit changes**.
3. Через 5 минут в **Actions** будет новый APK.

Если хотите, чтобы старая версия обновилась поверх, а не встала второй иконкой,
поднимите `versionCode` в `app/build.gradle` на единицу перед сборкой.

---

## Сборка у себя на компьютере

Понадобится Android Studio.

1. **File → Open**, выберите эту папку.
2. Студия сама скачает Gradle и SDK, первый раз это долго.
3. **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
4. Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

## Что где лежит

| Файл | Зачем |
|---|---|
| `app/src/main/assets/index.html` | само приложение: разметка, стили, вся логика расчётов |
| `app/src/main/java/com/uchet/app/MainActivity.java` | окно WebView, «назад», сохранение CSV |
| `app/src/main/res/mipmap-*/` | иконки приложения |
| `app/src/main/res/values/themes.xml` | цвет строки состояния, светлая тема |
| `app/src/main/res/values-night/themes.xml` | то же для тёмной темы |
| `app/build.gradle` | версия приложения, минимальная версия Android (7.0) |
| `.github/workflows/main.yml` | инструкция для GitHub, как собирать APK |

## Где хранятся данные

Внутри приложения, в его собственном хранилище. Баланс, остаток, локации,
тарифы и история переживают перезапуск и обновление приложения, но удаляются
вместе с приложением. Резервная копия — кнопка «Экспорт CSV» в разделе «История»,
файл ложится в папку «Загрузки».
