# PQS

Приложение для Android. Прячет фото из галереи в собственное хранилище.

---

## Как залить репозиторий на GitHub

### Если репозитория ещё нет

1. На GitHub нажмите **+** → **New repository**, задайте имя и нажмите
   **Create repository**. Ничего не отмечайте — ни README, ни .gitignore.
2. В папке с проектом выполните:

```bash
git init
git add .
git commit -m "Первая версия"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ.git
git push -u origin main
```

Вместо пароля GitHub попросит токен: **Settings → Developer settings →
Personal access tokens → Tokens (classic) → Generate new token**, отметьте
права `repo` и `workflow`.

### Если репозиторий уже есть

```bash
git add .
git commit -m "Что изменилось"
git push
```

### Через сайт, без командной строки

Откройте репозиторий → **Add file** → **Upload files** → перетащите папку
проекта → **Commit changes**.

## Как получить APK

Сборка идёт на серверах GitHub, ничего устанавливать не нужно.

1. Откройте репозиторий на GitHub → вкладка **Actions**.
2. Слева выберите **Сборка APK**.
3. Нажмите **Run workflow** → ещё раз **Run workflow**.
   Сборка запускается и сама при каждом `push` в `main`.
4. Подождите около минуты и откройте завершившийся прогон.
5. Внизу страницы, в разделе **Artifacts**, скачайте **pqs-apk** — это
   zip-архив.
6. Распакуйте его. Внутри `app-debug.apk` — это и есть приложение.

Если прогон завершился с красным крестиком, рядом лежит артефакт
**log-sborki** с полным логом сборки.

### Установка на телефон

Скопируйте `app-debug.apk` на телефон и откройте его. Android спросит
разрешение устанавливать приложения из этого источника — разрешите.

Версия приложения видна в **Настройки → Приложения → PQS** и совпадает
с номером прогона сборки: `1.0.28` — это прогон №28.

## Обновление поверх установленного

APK подписывается постоянным ключом из папки `signing/`, поэтому новая
версия ставится поверх старой и фото в тайнике сохраняются.

Исключение — самая первая установка после перехода на постоянный ключ:
тогда старое приложение нужно удалить. **Перед удалением верните нужные
фото в галерею кнопкой «в галерею»** — при удалении приложения тайник
стирается вместе с ним.

---

## Вход в приложение

Приложение открывается партией в крестики-нолики. Последовательность ваших
ходов — это ключ. При первом запуске приложение попросит её задать: сыграйте
партию, сделав хотя бы один ход с удержанием (нажать и подержать секунду).

Комбинация нигде не хранится в открытом виде и не восстанавливается.
Сменить её можно в справке внутри приложения, пока оно открыто.
